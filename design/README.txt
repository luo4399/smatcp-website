把 Figma 导出的设计稿 PNG 放进这个目录，我就能直接读取并照着改。

Figma 导出步骤：
1. 打开文件 https://www.figma.com/design/9Y2gvL9DlNub00GQJfDamw/GTOP官网
2. 左侧画板列表里选中要还原的 Frame（可按住 Shift 多选）
3. 右下角 Export 面板：格式选 PNG，倍率选 2x（清晰度够，我这边能看清文字）
4. 点 Export，把导出的文件全部拖进本目录

文件名不用讲究，按 Figma 里的 Frame 名最好（例如 Home.png / Donors.png / Somatic-data-List.png）。
